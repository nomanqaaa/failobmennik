# Защищённый файлообменник

Браузерный файлообменник для передачи небольших файлов между пользователями. Проект использует Cloudflare Workers и Workers KV для обработки запросов и хранения данных. Шифрование файлов выполняется на стороне клиента.

Демо: https://public-file-share.freshplay905.workers.dev/

Репозиторий: https://github.com/nomanqaaa/failobmennik

## О проекте

Проект предназначен для временного обмена файлами между пользователями через браузер. Отправитель загружает файл и передаёт получателю ссылку для доступа к нему. В зависимости от реализованного механизма защиты для получения исходного содержимого может потребоваться пароль.

Сервис не требует установки отдельного приложения и может быть развёрнут в собственном аккаунте Cloudflare.

## Основные возможности

- Передача файлов через веб-интерфейс.
- Клиентское шифрование файлов перед загрузкой.
- Защита доступа к файлам паролем, если предусмотрена текущей реализацией.
- Создание ссылок для получения файлов.
- Временное хранение данных с использованием TTL.
- Удаление файлов средствами серверной логики.
- Использование Cloudflare Workers и Workers KV.
- Возможность самостоятельного развёртывания проекта.

## Принцип работы

1. Пользователь открывает сайт и выбирает файл.
2. Браузер выполняет предусмотренную приложением обработку и шифрование файла.
3. Данные отправляются на Cloudflare Worker.
4. Worker обрабатывает запрос и сохраняет данные в Workers KV.
5. Пользователь передаёт получателю ссылку на файл.
6. Получатель открывает ссылку и получает сохранённые данные.
7. Если файл зашифрован, браузер выполняет расшифровку в соответствии с реализованным механизмом.
8. По истечении срока хранения файл должен стать недоступным в соответствии с логикой TTL.

## Используемые технологии

- Cloudflare Workers — обработка HTTP-запросов и серверная логика.
- Cloudflare Workers KV — хранение данных и метаданных файлов.
- HTML — структура веб-интерфейса.
- CSS — оформление интерфейса.
- JavaScript — клиентская логика приложения.
- Web Crypto API — криптографические операции в браузере, если используется в реализации.
- Wrangler — настройка и развёртывание приложения.

## Требования

Для самостоятельного развёртывания необходимы:

- Аккаунт Cloudflare.

- Wrangler CLI.
- Пространство Workers KV.
- Настроенная конфигурация проекта.

## Установка и развёртывание

### 1. Клонирование репозитория

```bash
git clone https://github.com/nomanqaaa/failobmennik.git
cd failobmennik
```

### 2. Установка Wrangler

```bash
npm install -g wrangler
```

### 3. Авторизация в Cloudflare

```bash
wrangler login
```

### 4. Настройка проекта

Откройте `wrangler.toml` и проверьте настройки приложения, дату совместимости, статические ресурсы и привязки Workers KV.

При развёртывании в собственном аккаунте Cloudflare укажите идентификатор своего пространства KV. Не используйте чужие секреты или учётные данные.

### 5. Публикация

```bash
wrangler deploy
```

После успешного развёртывания Wrangler выведет адрес приложения.

Команды и настройки необходимо сверить с текущей версией конфигурационных файлов проекта.

## Ограничения

- Проект предназначен для обмена небольшими файлами.
- Практический максимальный размер файла зависит от реализации приложения и ограничений используемых сервисов.
- Cloudflare Workers и Workers KV имеют ограничения, зависящие от тарифа.
- Доступность файла после истечения TTL зависит от серверной логики.
- Шифрование не защищает от утечки ссылки, слабого пароля и ошибок реализации.

## Безопасность

Перед использованием сервиса рекомендуется учитывать следующие меры предосторожности:

- Использовать сложные пароли.
- Передавать пароль получателю по отдельному каналу связи.
- Не публиковать ссылки на конфиденциальные файлы.
- Не хранить секретные ключи, токены и пароли в публичном репозитории.
- Проверять реализацию шифрования, удаления и ограничения доступа перед использованием для чувствительных данных.

Проект не следует считать прошедшим независимый аудит безопасности без соответствующей проверки.

Проект предназначен для личного обмена файлами и изучения разработки serverless-приложений с использованием Cloudflare Workers, Workers KV и клиентского шифрования.
