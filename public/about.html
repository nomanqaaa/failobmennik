Как это работает

Четыре шага от файла до скачивания

Сервер видит только зашифрованные данные.

Выбор файла

Отправитель выбирает файл, придумывает пароль (от 10 символов) и срок.

Шифрование

Из пароля через PBKDF2 получается ключ, файл шифруется AES-GCM в браузере.

Ссылка

Worker кладёт шифртекст в KV и возвращает уникальную ссылку.

Скачивание

Получатель вводит пароль, браузер расшифровывает файл, ссылка сгорает.

Безопасность

Что защищено, а что нет

Честно о модели защиты, чтобы вы понимали, что именно получаете.

ШифрAES-GCM, ключ 256 бит
Вывод ключаPBKDF2, SHA-256, 250 000 итераций
Соль / IVслучайные, 16 и 12 байт на каждый файл
Токен ссылки48 hex-символов (192 бита случайности)
ХранилищеWorkers KV с TTL

Важно знать

  • Пароль передавайте отдельно от ссылки и по другому каналу.
  • Забытый пароль восстановить нельзя — файл не расшифровать.
  • Имя файла, тип и размер хранятся на сервере в открытом виде.
  • Стойкость зависит от длины пароля: берите длинную фразу.
  • Это прототип: он не заменяет полноценный аудит безопасности.

Развёртывание

Запустите свой файлообменник

Понадобятся Node.js и бесплатный аккаунт Cloudflare.

# 1. Клонируйте репозиторий
git clone https://github.com/nomanqaaa/failobmennik
cd failobmennik

# 2. Создайте хранилище и впишите его id в wrangler.toml
npx wrangler kv namespace create FILES

# 3. Опубликуйте
npx wrangler deploy
