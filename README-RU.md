# Защищённый файлообменник — вариант без привязки карты

Этот вариант использует **Cloudflare Workers + Workers KV** вместо R2. Workers KV входит в бесплатный тариф Workers и, в отличие от R2, обычно не требует добавления платёжного метода. Сайт и API публикуются одним Worker; отдельный Cloudflare Pages не нужен.

## Ограничения бесплатного варианта

- Максимальный исходный файл — **18 МБ**: зашифрованное содержимое кодируется в Base64, из-за чего запись становится больше. KV допускает до 25 MiB на одно значение.
- Бесплатный Workers KV: до 1 GB хранилища, 100 000 чтений в день и 1 000 операций записи/удаления/списка в день. При превышении лимитов запросы этого типа могут завершаться ошибкой, а не автоматически переходить на платную оплату.
- Это небольшой публичный проект, а не неограниченный сервис. Ссылки случайные, файлы шифруются в браузере, срок хранения задаётся в интерфейсе. KV распространяет данные с eventual consistency, поэтому после загрузки на разных узлах иногда возможна короткая задержка появления записи.
- Удаление после скачивания реализовано последовательностью чтения и удаления, а не атомарной транзакцией. Не используйте прототип для единственной копии критически важных данных.

## Настройка на Windows PowerShell

1. Распакуйте архив в отдельную папку и откройте PowerShell в этой папке. В ней должны быть `worker.js`, `wrangler.toml` и папка `public`.
2. Войдите в Cloudflare, если ещё не вошли:

   ```powershell
   wrangler login
   ```

3. Создайте бесплатное KV-хранилище:

   ```powershell
   wrangler kv namespace create FILES
   ```

   В выводе появится `id`, обычно похожий на длинную строку в кавычках. Скопируйте его.

4. Откройте `wrangler.toml` в Блокноте:

   ```powershell
   notepad wrangler.toml
   ```

   Замените `REPLACE_WITH_NAMESPACE_ID` на полученный ID. Сохраните файл. Не меняйте `binding = "FILES"`.

5. Опубликуйте сайт вместе с API:

   ```powershell
   wrangler deploy
   ```

6. В конце вывода появится адрес вида `https://public-file-share.<ваш-поддомен>.workers.dev`. Откройте его в браузере. На этом всё — отдельный Pages-проект и R2 не нужны.

## Проверка

- Откройте сайт в обычном окне браузера.
- Выберите небольшой тестовый файл и задайте пароль длиной не менее 10 символов.
- Скопируйте полученную ссылку и откройте её в другом браузере или приватном окне.
- Передайте пароль получателю отдельно от ссылки и проверьте скачивание.

## Если возникла ошибка

Пришлите текст ошибки из PowerShell, но не присылайте секретные токены и пароли. Если команда `wrangler kv namespace create FILES` сообщает, что имя занято, создайте namespace с другим уникальным именем и согласованно измените `binding` в `wrangler.toml` и в коде Worker.
